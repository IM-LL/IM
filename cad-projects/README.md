# Mechanical Engineering & AutoCAD Projects

Welcome to my **CAD & Mechanical Engineering Projects** repository folder.

This directory contains 2D & 3D AutoCAD drafting files, engineering schematics, component models, and technical drawings created as part of my Mechanical Engineering studies and side projects.

## Project Structure

- `2d-drafting/` - Orthographic projections, dimensioned mechanical components, and assembly blueprints (.dwg, .pdf)
- `3d-modeling/` - 3D solid models, mechanical parts, and isometric renders (.dwg, .step)
- `schematics/` - Piping, hydraulic, and mechanical system layout diagrams (.dwg, .pdf)

## Software Used

- **AutoCAD** (2D Drafting & 3D Mechanical Modeling)
